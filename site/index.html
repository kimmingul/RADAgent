기능

IDE가 하는 일을
에이전트도 합니다.

터미널 에이전트를 IDE 옆에 띄우는 것이 아니라, IDE의 기능을 에이전트 도구로 엽니다.

도킹 채팅

마크다운 답, 누르면 에디터가 열리는 파일 위치, 묶어서 보이는 도구 호출. 작업 중에도 Enter로 끼워 넣고 Ctrl+Enter로 턴 뒤에 보냅니다.

끼워 넣기/btw 곁가지 질문

에디터와 디스크 동기화

보내기 전에 저장하고, omp가 고친 파일은 IDE가 다시 읽습니다. 그 사이 직접 고치던 파일은 덮어쓰지 않고 충돌로 알립니다.

저장 · 다시 읽기충돌 알림

폼 디자이너

컴포넌트 추가·삭제·이름 변경, 속성과 이벤트 연결을 디자이너로 합니다. 폼 스크린샷으로 레이아웃을 눈으로 확인하고, 여러 폼의 속성은 한 번에 고칩니다.

VCL · FMX폼 스크린샷

컴파일 · 메시지 뷰

활성 프로젝트를 빌드하고 오류를 메시지 뷰에 올립니다. C++Builder는 실패한 .cpp를 다시 컴파일해 파일·줄·메시지를 모델에 돌려줍니다.

Delphi · C++Builder

디버거

호출 스택, 부작용 없는 식 평가, 중단점 목록을 읽고, 승인하면 실행·스텝·일시 정지·종료와 중단점 추가까지 합니다.

스텝 over/into/return

git 체크포인트

메시지마다 보내기 직전 상태를 남깁니다. 내 브랜치·index·HEAD는 그대로. 메시지에서 파일과 대화를 함께 되돌리거나, 거기서 브랜치를 만듭니다.

되돌리기브랜치

코드 탐색 (LSP)

Delphi는 IDE 설치본의 DelphiLSP를, C++Builder는 clangd를 연결합니다. clangd는 설정 창에서 받아 설치하고 컴파일러가 쓰는 헤더·매크로로 설정됩니다.

DelphiLSPclangd

모델은 내가 고릅니다

Claude, GPT, Gemini, Ollama 로컬 모델까지 omp가 지원하는 공급자를 내 계정으로 씁니다. 역할별 모델(기본·빠른·느린·계획·하위 에이전트)도 프로젝트마다 정합니다.

역할별 모델MCP · 스킬 · 플러그인

사용량이 한눈에

컨텍스트 원을 누르면 컨텍스트 윈도우와 이 세션의 토큰·비용, 공급자 플랜의 5시간·주간 한도와 재설정 시각이 보입니다.

플랜 한도

바꾸기 전에

거부승인

코드는 PC에, 모델은 내 계정으로.

RAD Agent는 IDE 안의 패키지이고, 에이전트는 이 PC의 omp가 돌립니다. 모델 요청은 omp가 내가 로그인한 공급자로 보냅니다. RAD Agent 자체는 어떤 서버에도 데이터를 보내지 않습니다.
